About this map

An isometric pixel-art map of Imphal, drawn entirely by code from open map data. No photographs or satellite images appear in it.

The geography is real: roads, rivers, building footprints, and most building heights come from the sources below. Ordinary buildings are drawn from a small set of types, so tree positions, roof types, roof colors, windows, and paddy field outlines are illustrative.

Help improve this map

If you know Imphal, you can help. Use "Suggest a correction" on the map, or read the contributing guide. We especially want to know:

  • Where exactly the citadel walls stand inside Kangla
  • Where the Hijagang, the royal boatyard, is
  • Whether the Shaheed Minar is in the right place in Bir Tikendrajit Park
  • The preferred spelling of Uttra Shanglen
  • Openly licensed photos of RIMS, Manipur University, the State Museum, and Khuman Lampak Stadium, so that we can draw them
