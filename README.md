# Manipur

> An isometric pixel-art map of Manipur.
Built entirely from free and openly licensed map data. No photographs, no satellite imagery in the output, no scraped tiles. Every pixel is rendered from vectors and open rasters by code, so the whole map can be regenerated in minutes whenever the underlying data improves.

Google has no 3D mesh for any Indian city, so this project takes the other road: a procedural SimCity-style renderer over OpenStreetMap, Google Open Buildings, Copernicus DEM and ESA WorldCover, with hand-placed pixel-art sprites for landmarks.

The look and the method owe more to:

- SimCity 2000, for the 2:1 dimetric view and a small vocabulary of building types.
- [osm-isometric-3d](https://github.com/bitsteller/osm-isometric-3d) and [OSM2World](https://osm2world.org/), which showed that isometric maps can be drawn straight from OpenStreetMap.
